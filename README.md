# Digital Logic Design Laboratory

A collection of combinational and sequential digital circuits designed,
constructed, tested, and documented using TTL integrated circuits on
solderless breadboards.

## Overview

This repository contains selected work from my Digital Logic Design
Laboratory at the University of Missouri–Kansas City.

The projects demonstrate experience with:

- Boolean algebra and logic minimization
- TTL integrated circuits
- Binary arithmetic circuits
- Multiplexers and decoders
- D and JK flip-flops
- Shift registers
- Synchronous and asynchronous counters
- State tables and state diagrams
- Breadboard construction and circuit debugging

## Featured Projects

### Four-Bit Multifunction Register

Designed and implemented a four-bit register supporting hold, parallel
load, shift-left, and shift-right operations using D flip-flops and
multiplexers.

[View Project](sequential-circuits/multifunction-register/)

### Synchronous and Asynchronous Decade Counters

Designed and tested two decade-counter architectures using D and JK
flip-flops and an external clock source.

[View Project](sequential-circuits/counters/)

### Four-Bit Adder/Subtractor

Constructed a combinational circuit capable of binary addition and
two's-complement subtraction.

[View Project](combinational-circuits/adder-subtractor/)

### Sequential Logic Design

Translated state equations into state tables, logic diagrams, and
physical circuits using D and JK flip-flops.

[View Project](sequential-circuits/sequential-logic-design/)
